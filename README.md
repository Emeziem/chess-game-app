# Chess Game App

This desktop application lets you play chess against the Stockfish engine on your computer. The app provides the board and game controls, while Stockfish acts as the AI opponent.

## What you need

Before using the app, make sure you have:

- the desktop application installed or available on your machine
- the Stockfish engine downloaded on your computer
- the path to the Stockfish executable

## Download Stockfish

1. Visit the official Stockfish website: https://stockfishchess.org/download/
2. Download the version that matches your operating system.
3. Extract the downloaded files if needed.
4. Locate the Stockfish executable file:
   - **Windows:** usually `stockfish.exe`
   - **macOS/Linux:** usually `stockfish`

## How to play against the AI

1. Open the desktop application.
2. Start a new game or choose the option to play against the computer.
3. When prompted for a chess engine, browse to and select the Stockfish executable on your machine.
4. Choose any available AI settings in the app, such as skill level, search depth, or time control.
5. Select the color you want to play as, if the app provides that option.
6. Start the match.
7. Make your moves on the board in the desktop app. After each move, the app sends the position to Stockfish and shows the engine's reply move.

## Tips

- Use a lower Stockfish skill level if you want a more beginner-friendly game.
- Increase the engine strength or search depth for a tougher opponent.
- If the app supports analysis, you can review moves after the game using the same Stockfish engine.

## Troubleshooting

- If the app cannot find Stockfish, confirm that you selected the executable file and not just the folder.
- If Stockfish does not start, make sure you downloaded the correct version for your operating system.
- If the engine still does not load, close the app, reopen it, and reselect the Stockfish executable path.
